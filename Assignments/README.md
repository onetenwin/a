# CN Lab Assignments
- `Assignment2_TCP_UDP_Student_Server/` – TCP (pthread) & UDP student record server/client
- `Assignment3_HTTP_Client/` – HTTP client over TCP sockets (+ optional OpenSSL HTTPS client)
- `Assignment5_DNS_UDP/` – DNS simulation over UDP with cache, timeout, CRC, PDR/RTT stats

Each folder has its own `Makefile` and `GUIDE.md`. Build with `make` inside the folder (Linux/WSL, gcc).
